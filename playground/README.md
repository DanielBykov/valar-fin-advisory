# Playground

Static HTML prototypes for experimenting with layouts, styles, and content before implementing them in the main website.

## Usage

Open any `.html` file directly in a browser — no server or build tools needed.

## Guidelines

- Keep each prototype self-contained (inline styles/scripts, or local asset files).
- Name files descriptively: `homepage-v1.html`, `contact-form.html`, etc.
- This folder is for quick iteration. Polished versions move to `web/`.
