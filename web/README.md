# Web

The main Valar Finance & Mortgage Advisory website, built with [Next.js](https://nextjs.org/).

## Prerequisites

- Node.js 18+
- npm, yarn, or pnpm

## Getting started

```bash
cd web
npm install
npm run dev
```

The site will be available at `http://localhost:3000`.

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start development server     |
| `npm run build`   | Create production build      |
| `npm run start`   | Serve production build       |
| `npm run lint`    | Run linter                   |
