# Docs

Project documentation, research, ideas, and planning materials for Valar Finance & Mortgage Advisory.

## What goes here

- Market research and competitor analysis
- Feature ideas and product roadmaps
- Meeting notes and decisions
- Content drafts (copy, FAQ, etc.)
- Regulatory and compliance notes

## Conventions

- Use Markdown (`.md`) files for text content.
- Prefix file names with a date (`2025-05-26-topic.md`) when order matters.
- Keep one topic per file.
