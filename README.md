# Valar Finance & Mortgage Advisory

Website and resources for Valar Finance & Mortgage Advisory.

## Repository structure

```
├── web/           # Next.js website (for developers)

```

## Getting started

See [web/README.md](web/README.md) for setup instructions.

### Docs

### Playground

Open any HTML file from [playground/](playground/) directly in a browser — no build step required.
